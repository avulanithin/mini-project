Purpose

Help camp organizers plan and optimize blood donation camps by simulating donor arrivals, queue behavior, and staff utilization before the actual event.

📊

Key Features

  • Multi-stage simulation — Registration → Screening → Donation
  • Poisson arrival process modeling
  • Multiple parallel service counters
  • Real-time queue statistics
  • Server utilization analysis
  • Scenario comparison tools
🔬

Simulation Model

Arrival Distribution: Poisson process

Service Time: Exponential / Uniform

Queue Discipline: First-Come-First-Serve (FCFS)

System Type: Multi-server, multi-stage queuing

🎓

Problem Statement

Blood donation camps face resource allocation and queue management challenges. This simulation answers:

  • How many service counters are needed?
  • What are expected wait times?
  • How to minimize donor waiting time?
  • What is optimal staff allocation?
